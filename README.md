## 🚀 Selected Research

### 4D Asset Pipeline

An object-centric asset curation pipeline for building reusable 3D/4D assets from real-world driving scenes.

The pipeline includes:

* Open-vocabulary object discovery and segmentation
* GroundingDINO and SAM2-based asset extraction
* Foreground mask and RGBA generation
* Quality-aware asset curation
* Hunyuan / TRELLIS handoff for 3D generation
* Preparation of reusable assets for driving-scene reconstruction and simulation

**Repository:** [4D-Asset-Pipeline](https://github.com/jincenou/4D-Asset-Pipeline)
